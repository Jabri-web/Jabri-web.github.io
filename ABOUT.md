## 📖 About This Repository

This repository is the **primary organizational hub** for the entire Jabri-web ecosystem. It serves as the main index and gateway to all projects, from the `Zx_Mother_Function_Jabri` to `Jabri_RiemannOS`. **Every project on the Jabri-web organization points back to this repository as its central reference.**

**Key Features:**
- **Central Navigation:** A comprehensive list of all repositories and their live GitHub Pages.
- **DOI Hub:** Aggregated links to all published DOIs, making citation easy.
- **Research Overview:** A summary of the Zx Mother Function, Millennium Problems, and Yemeni heritage documentation.
- **GitHub Stats:** Live badges showing profile views, stars, and followers.
- **Unified Branding:** Consistent license (CC BY 4.0) and Jabri Identity (`Z + C + A = 1`) across all projects.
