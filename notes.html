🎯 M1: Disable Screen (تعطيل الشاشة)

📅 2026-09-22 ⭐ أولوية: متوسطة ⏱️ 1-2 يوم 🔒 مؤجلة

الوصف

عند الضغط على زر معين ← تعطيل الشاشة الكاملة:

  • 🔒 غطاء شفاف فوق كل العناصر
  • ⏳ رسالة "جارٍ التحميل..." أو "الرجاء الانتظار"
  • ✅ زر "موافق" عند الانتهاء
  • 🚫 منع الضغط المزدوج

المشكلة التي تحلها

المستخدم عندما يضغط زر في واحة الجبري:

  • يظهر بطء في التحميل
  • أو: الزر لا يستجيب
  • النتيجة: يحاول مرة أخرى ← طلبات مكررة
  • الحل: تعطيل الشاشة مع رسالة واضحة

الصيغ الثلاث

1️⃣ Disable Partial (جزئي)

document.getElementById('menu').disabled = true; // تعطيل جزء معين فقط

2️⃣ Disable Whole Screen (كامل)

overlay.style.display = 'block'; // غطاء على كل الشاشة

3️⃣ Disable for Users (صلاحيات)

if (userRole === 'viewer') { // عرض فقط — لا أزرار }

أماكن التطبيق في الواحة

  • عند تبديل اللغة
  • عند فتح APK
  • عند تحميل menu.js
  • عند التنقل بين الصفحات
  • للزوار غير المسجلين (لاحقاً)
  • للمشرفين (لاحقاً)

الفوائد

  • UX أفضل — المستخدم يعرف أن الموقع يعمل
  • منع أخطاء — لا ضغط مزدوج
  • منع 404 إضافية — لا طلبات مكررة
  • صلاحيات — في المستقبل: زائر / مسجل / مشرف
  • مظهر احترافي — يشبه التطبيقات الحقيقية

ملاحظات تقنية

  • الملف المقترح: /js/ux.js جديد
  • يُضاف في: header.html (بعد menu.js)
  • يحترم prefers-reduced-motion
  • يعمل على: ويب + APK
  • لا يعمل في: Googlebot (IS_BOT)
