تنبيهات اصطلاحية صريحة:

  • \(x_p = 21\): اختيار نمذجي حرّ مستوحى من \(\gamma_2 \approx 21.022\)، وليس اشتقاقًا من دالة زيتا. التفصيل في §1 من Frame 1.
  • \(A(x)\) في هذه الصفحة: الصيغة (x/xp)² e^(-x/xp) هي "وكيل مبسّط" (simplified proxy) يخدم السرد المفاهيمي. المعرّف الرسمي في Frame 1 هو A(x) = ∫₁ˣ Z(t;21) dt، وله براهين منفصلة.
  • \(Z_t = Z + C + A = 1\): هوية جبرية بالبناء (لأن \(C \equiv 1 - Z - A\))، وليست نتيجة طيفية ولا تنبؤًا فيزيائيًّا.
  • عدّاد أصفار \(Z\): في كود §2 أدناه، يعدّ أصفار الدالة النموذجية \(Z(x)\)، لا أصفار دالة زيتا.

# ============================================================
#   عدّ أصفار الدالة النموذجية Z(x) عند x = 0.5 + it
#   ⚠️ تنبيه: هذه أصفار Z النموذجية، وليست أصفار دالة زيتا.
#      راجع Frame 1 §1 للتمييز بين Z(x) و ζ(s).
# ============================================================

import numpy as np

def Z_of_t(t, xp):
    x = complex(0.5, t)
    return np.exp(-x/xp) * (x**-5) * np.log(x) * np.sin(2*np.pi / x)

def count_zeros(xp, t_max=100, step=0.02):
    ts = np.arange(0.01, t_max, step)
    ims = np.array([Z_of_t(t, xp).imag for t in ts])
    zeros = 0
    for i in range(1, len(ims)):
        if ims[i-1]*ims[i] < 0:
            zeros += 1
    return zeros

print("xp | 0-60 | 0-100   (أصفار Z النموذجية)")
for xp in [5, 10, 18, 21, 50]:
    print(xp, count_zeros(xp, 60), count_zeros(xp, 100))
